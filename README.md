# Library Adventure

Library Adventure adalah website edukasi untuk anak TK–SD yang mengenalkan perpustakaan melalui pengalaman belajar interaktif. Proyek ini menggunakan HTML, CSS, dan JavaScript ES Modules murni tanpa framework, langkah build, atau backend.

## Cara menjalankan

Jalankan server lokal dari folder proyek, misalnya dengan Live Server atau perintah `python3 -m http.server`, lalu buka alamat lokal yang ditampilkan. ES Modules dan `fetch` tidak berjalan jika halaman dibuka melalui `file://`.

## Struktur folder

- `css/` — gaya dasar, tata letak, layar, permainan, dan dialog.
- `js/core/` — kerangka modul inti aplikasi.
- `js/screens/` — kerangka layar pembuka, dunia, dan tutorial.
- `js/games/` — kerangka permainan.
- `data/` — berkas JSON untuk konten awal.
- `assets/` — tempat aset SVG, audio, dan ikon.
